# 💼 PET проекты:

📌 **Кулинарная платформа "Рецептограф"** <br>
Создал интерактивное веб-приложение, которое позволяет пользователям регистрироваться, создавать и делиться своими любимыми рецептами. Удобный интерфейс для поиска, сохранения в избранное и оставления комментариев к рецептам делает кулинарию доступной и увлекательной для каждого!
