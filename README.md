## 📌 «Cистема оптимизации энергопотребления в умном доме с использованием алгоритмов Deep Q-Learning»
#### Цель данной работы заключается в разработке системы управления энергопотреблением в умном доме, используя алгоритм глубокого обучения на основе Q-обучения (Deep Q-Learning). Система направлена на минимизацию затрат на электроэнергию путем оптимального распределения нагрузки между устройствами дома, учитывая доступные ресурсы и тарифные планы энергоснабжения.<br>
 <br>
 **Стек:** Python, Tensorflow, Keras, Seaborn, Plotly, Matplotlib <br>
[Ссылка на проект GitHub](https://github.com/lamauspex/DeepEcoHome) <br>
